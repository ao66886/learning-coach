# learning-coach · 通用学习教练

> 一套可复制到**任意 AI、任意学科**的学习流程提示词（Prompt）与技能（Skill）。
> 它不回答知识问题，只做四件事：**建档定靶 · 诊断 · 排路线 · 出题批改**。

## 这个仓库解决什么问题

大部分「AI 辅导学习」的失败，不是模型不够聪明，而是**流程不对**。下面五个坑，踩过任何一个，学完都等于没学：

| 坑 | 典型症状 | 本仓库的解法 |
|---|---|---|
| **没有靶子** | 打开网课从第一集开始刷，刷到第 9 集发现不考 | 先做**题型分布表**，再决定学什么 |
| **只听不产** | “听进去了”“感觉懂了”，一周后一片空白 | **交付物三件**，交不出＝没学会 |
| **课程堆叠** | 三门课加起来 158 小时，一门也看不完 | 资源**分职能**（原理/做题/题源/诊断），各取一段 |
| **换 AI 就断档** | 从 A 换到 B，进度全部重讲 | **学习档案卡**，把状态外置成一张卡 |
| **AI 退化成答疑机** | 问一句答一句，永远推不动 | 7 条**自检清单** + 纠偏话术 |

## 它怎么跑

```
① 判学科类型（计算 / 记忆 / 技能 / 综合）
        ↓
② 收五个数（考核日期 · 题源 · 教材 · 进度 · 每日投入）
        ↓
③ 填「学习档案卡」  ← 跨 AI 交接的唯一凭证
        ↓
④ 定靶：题型分布表（章节 × 题号 × 分值 × 问法 × 频次）
        ↓
⑤ 诊断：5 题覆盖层级结构的每一层 → 定起点
        ↓
⑥ 排路线：按依赖链分 4–5 阶段，每阶段有可验证的验收线
        ↓
⑦ 日课六项 → 批改 → 变式 → 更新档案卡 → 回到 ⑦
```

**关键在第 ④ 步。** 没有题型分布表就开始学习，是这类学习失败的第一原因——包括所有“哪门网课更好”的问题，答案都应该由卷子决定，而不是由口碑决定。

## 快速开始

### 方式一：贴给任意 AI（豆包 / ChatGPT / Claude / Kimi / 通义…）

1. 打开 [`prompt/learning-coach-zh.md`](prompt/learning-coach-zh.md)，复制 ```` ```text ```` 代码块里的全部内容。
2. 粘贴到该 AI 的**系统提示词 / 自定义指令**里（不要每条消息粘一次——放系统层，“顶回来”的力度才够）。
3. 把 `{{学科}}` 换成你要学的科目，然后说一句：**“开始”**。

它会先判学科类型、再向你要五个数，不会一上来给你背定义。

### 方式二：作为 WorkBuddy / Claude Skill 使用

```bash
git clone https://github.com/ao66886/learning-coach.git
cp -r learning-coach/skill/learning-coach ~/.workbuddy/skills/
```

之后直接说「学 XX」「帮我排学习路线」「当我的 XX 老师」就会自动触发，不用再粘提示词。

### 方式三：换 AI 续接（已有进度）

```text
1. 在旧 AI 里说：“输出当前学习档案卡”
2. 到新 AI 里：粘提示词 → 粘档案卡 → 说：
   “按这个档案继续，先复述我的起点和下一步”
```

不需要重讲历史，10 秒接上。

## 六条底层原则（冲突时以此为准）

| # | 原则 | 一句话解释 |
|---|---|---|
| 1 | **定靶优先于学习** | 课程推荐服从卷子，不服从口碑 |
| 2 | **判断优先于计算** | 分数集中在“判断”上；判断错了，公式再漂亮也是零分 |
| 3 | **输出优先于输入** | 留存靠“手画 + 立刻做题”，不靠“听明白” |
| 4 | **资源分职能，不分好坏** | 不存在“最好的一门课”，混着用必然浪费 |
| 5 | **档案卡优先于记忆** | 任何 AI 都没有跨会话记忆，可复现＝状态外置 |
| 6 | **考点优先于知识点** | “重要”不是理由，“会考”才是。区分考点课与支撑课 |

## 学科类型分流（决定整套流程怎么走）

同一套骨架，四种走法。AI 第一步会先判定你属于哪一类：

| 类型 | 典型学科 | 定靶产物 | 核心动作 | 头号死因 |
|---|---|---|---|---|
| **A 计算型** | 数学、电路、物理、力学 | 题型分布表 | 一手推导 + 变式 | 只看不推 |
| **B 记忆型** | 医学、法学、历史、政治 | 考点频次表 | 主动回忆 + 间隔重复 | 反复阅读的熟悉感错觉 |
| **C 技能型** | 编程、外语口语、写作、实验 | 能力清单 + 作品清单 | 最小可执行任务 + 即时反馈 | 只看教程不动手 |
| **D 综合型** | 考研专业课、资格证 | 混合 | 先 A 搭框架，再 B 填细节 | 平均用力 |

每类都有独立的**执行纪律五条**。例如 B 型第一条是「只读一遍，立刻合上复述」，C 型第一条是「5 分钟内必须看到结果」——都是针对该类学科最大的时间黑洞写的。

## 特色功能：康奈尔左栏卡

面向用康奈尔笔记法的人。每次日课，AI 除了给学习任务，还会生成一张**可整块截图的窄栏卡**，直接贴进笔记左栏（提示栏）。

- 左栏**只写提问和线索，绝不写答案**——写了就等于帮你偷看
- **5–7 行封顶**，每行 ≤10–12 字，一句话一个线索
- 每行必须标**「考在哪」**（哪个题型、哪道题）；标不出去处的直接删
- 固定四组：`①②③ 因果链` / `★ 必答` / `? 卡住 ⊘ 跳过` / `▣ 产出`
- 底部一行写**唯一判定标准**（如“4 个 ★ 全答出＝这课过了”）

用法只有一条：**听完盖住右边，只看左栏自测。** 答得出＝过了；答不出＝重推，不要重听整集。

模板见 [`templates/cornell-cue-card.html`](templates/cornell-cue-card.html)，真实案例见 [`examples/analog-electronics/`](examples/analog-electronics/)。

## 实战案例：模拟电子技术

[`examples/analog-electronics/`](examples/analog-electronics/) 是一份**真实跑完整套流程**的存档，可以直接看出来这套东西长什么样：

- 教材：康华光《电子技术基础 模拟部分》第 7 版
- 题源：7 个分章题库，65 道题，全部带解答
- 产出：题型分布表（含“题库缺第 7、10 章 ⇒ 大概率不考”的反推）、考点映射表、7 张康奈尔左栏卡、1 份完整康奈尔笔记范例

其中三个可以直接迁移的判断：

1. **符号口径必须从答案里反推**。同一门课，教材写 `A_u`、题库答案写 `A_v`，判卷按后者给分。
2. **“必须会但不考的工具”不能删，只能压缩成结论**。判工作区不单独出题，但藏在每道大题的第二步。
3. **题目分布决定了哪里能快进**。题库缺哪章，比课件目录更能说明考什么。

## 适用 / 不适用

**适用**

- 有明确考核（期末 / 考研 / 考证），且有真题或题库
- 学过一遍但“没记住”，需要重建流程
- 手上有 2–3 门网课，不知道该看哪门、看多少
- 想用康奈尔笔记法，但不知道左栏写什么

**不适用**

- 纯兴趣学习、没有考核压力（流程会显得过重）
- 完全没有题源、也没有教材（只能给通用版，误差约三分之一）
- 需要 AI 直接给答案的场合（这套流程会顶回来，不给答案）

## 已知限制

- **任何 AI 都没有跨会话记忆**。换平台必须手动粘「学习档案卡」，这不是缺陷，是设计前提。
- **强依赖题源**。没有真题时只能按通用权重排，会浪费约三分之一时间，且 AI 会明确告知这一点。
- **中文提示词为主要版本**。英文版是精简版，覆盖主流程但不含全部细则。
- **A 型（计算型）打磨最充分**，因为最初的实战案例是电路课。B/C 型的纪律是通用化的推论，欢迎用真实案例来校准。
- 示例中的课程评价属个人观点，不构成推荐。
