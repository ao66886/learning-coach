# 设计原理

> 这份文档解释**每条规则为什么长这样**。你可以不同意，但应该知道它在防什么。
> 想改提示词的人先读这个，否则很容易把一条反直觉但关键的规则当成冗余删掉。

---

## 一、六条原则的来源

这六条不是从教育学理论里抄的，是**从一次失败的学习里反推出来的**。

起点：一门课，看过两三门网课，能听懂，进考场不会做。逐层追问“为什么”，得到六条：

### 1. 定靶优先于学习

**症状**：从第一集开始刷网课，刷到第 9 集发现后面不考。
**机制**：没有靶子时，学习由“课程结构”驱动，而不是由“考核结构”驱动。两者的差集往往超过 30%。
**结论**：先做题型分布表，再决定看哪几讲。**“哪门课更好”这个问题的答案，应该由卷子决定，不由口碑决定。**

### 2. 判断优先于计算

**症状**：公式都会背，题目一下手就错。
**机制**：这类学科的分数集中在“判断”上——判类型、判状态、判方向、判结构。判断对了，计算是初中数学；判断错了，公式再漂亮也是零分。
**结论**：教学顺序必须是“先教会判断，再教计算”。反过来教，学生会得到一堆用不上的公式。

### 3. 输出优先于输入

**症状**：“听进去了”“感觉懂了”，一周后一片空白。
**机制**：看视频会产生**流畅性错觉**——信息处理得顺，就被误判为已经掌握。留存需要的是提取练习（retrieval），不是再认（recognition）。
**结论**：每次学习必须有一个**交付物**，交不出＝没学会。这是“交付物三件”的全部理由。

### 4. 资源分职能，不分好坏

**症状**：三门课加起来 158 小时，一门也没看完。
**机制**：每门课都有它擅长的那一段。讲得透的不讲习题，讲习题的讲得浅。你把它们当“三个候选”在选，就会永远在选。
**结论**：分成四层——原理层 / 做题层 / 题源层 / 诊断层，各取所需，不整门看。

### 5. 档案卡优先于记忆

**症状**：从 GPT 换到 Claude，进度全部重讲。
**机制**：任何 LLM 都没有跨会话记忆。“可复现”不能指望模型，只能把状态**外置**成一个文件。
**结论**：学习档案卡。它必须自包含，不依赖任何历史对话——判断标准是：换一个 AI，只粘这张卡，它能复述出你的起点和下一步。

### 6. 考点优先于知识点

**症状**：花了三天学一个“很重要”的章节，考试 0 分。
**机制**：重要性是一个学科内部的属性，与你的考卷无关。决定投入量的是“卷面上有没有去处”。
**结论**：区分**考点课**（本身出题，练到能做对）与**支撑课**（只解释别人的考点，够用即止）。支撑课多学一步都是浪费。

## 二、几条反直觉但不要删的规则

| 规则 | 直觉会说 | 为什么保留 |
|---|---|---|
| **不记笔记，只画图** | 不记笔记怎么复习？ | 抄笔记让手在动、脑子在休息，产生“学过了”的错觉。图是记忆锚点，结论都能推 |
| **1.25 倍速封顶，禁止整段重听** | 听不懂当然要重听 | 整段重听是最容易“感觉很努力但什么也没发生”的操作。回退 30 秒足够 |
| **最多留 3 个不懂点** | 不懂怎么能跳过 | 第 4 个不懂点说明这一讲对你超纲了，硬啃的时间成本远高于回头补 |
| **“有印象但不会”按零基础处理** | 我明明听过 | “听过”和“会”是两件事，这个判断错误会让人跳过所有必要的基础动作 |
| **左栏卡最多 5–7 行** | 多写点不是更全？ | 左栏是自测栏。塞满了它就变成第二份笔记，自测功能消失 |
| **“粗心”不是一类错因** | 我就是粗心 | 写“粗心”等于放弃分析。它要么是推导失误，要么是读题失误，两者训练方式不同 |
| **低于 60 分不要重看视频** | 没学懂当然要再看 | 问题大概率在依赖链的上一环。重看只会更熟、不会更会 |

## 三、为什么是「依赖链」而不是「章节顺序」

教材按知识逻辑编排，路线要按**依赖成立顺序**编排。两者常常不同。

例子（模拟电子技术）：

```
教材顺序：二极管 → 场效应管 → 三极管 → 频响 → 集成运放 → 反馈 → 功放 → 电源
有效顺序：二极管模型 → MOSFET 放大（建立通用五步法） → BJT 放大（换器件重走一遍）
          → 频响 + 反馈（一起学） → 运放应用 → 功放电源
```

两处偏离：

- **先用 MOSFET 建立方法，再上 BJT。** 因为 MOS 只有 `g_m` 一个参数，没有 `i_B`、没有 `r_be`，注意力不会被器件细节分散。先学 BJT 的人几乎都卡在 `r_be` 那一步，然后把 MOS 学成“又要背一遍的器件”。
- **频响和反馈必须一起学。** 它们不是两个知识点，是同一件事的两面：**反馈是用牺牲增益换带宽和稳定性**。分开学，你只会算 `f_L`、`f_H`，不会答“加了反馈带宽变成多少倍”。

**判断依赖链的方法**：问“学 B 的时候，会不会反复用到 A？”会 → A 在 B 前面。不会 → 它们可以按收益排序。

## 四、为什么诊断按「层级」而不是按「题型」

题型诊断只能告诉你“会不会做这类题”，不能告诉你“卡在第几层”。

层级诊断（基础层 → 核心层 → 难点层 → 综合层 → 易错层）能直接定位起点：

| 答对 | 处理 |
|---|---|
| ≤2 题 | 从头走 |
| ≥3 题 | 跳过基础层 |
| 5 题全对 | 直接攻最难的部分 |

配套的特别规则是**“有印象但不会”＝零基础**。这条规则救过很多人：他们把“听过”当成了资产，于是跳过了所有必要动作，然后在考场上发现账户是空的。

## 五、康奈尔左栏卡：一个约束带来的设计

需求是：卡片可截图贴进康奈尔笔记左栏。这个物理约束（窄）推导出了全部设计：

1. **窄 ⇒ 必须删。** 所以有了“每行标考在哪，标不出去就删”。
2. **要能自测 ⇒ 不能写答案。** 写了答案，你只会读它，不会答它。
3. **要能判断过没过 ⇒ 底部必须有唯一判定标准。** 没有判定线的卡只是装饰。
4. **要敢快进 ⇒ 必须显式写“跳过什么”。** 否则你会因为“万一这里要考”而全程 1 倍速，最后没时间动手。

**这四条都是从“贴进左栏”这一个约束里长出来的**，不是额外的功能堆叠。改这张卡时，先问“这个改动会不会破坏左栏的自测功能”。

## 六、可选加强：把「学会」定义成三级

提示词里没有强制这一条，因为它对短周期冲刺来说过重。但如果你的周期超过一个月，建议加上：

| 级 | 判定方式 | 说明 |
|---|---|---|
| **L1 复述** | 合上材料，讲清“它解决什么问题、为什么这么设计” | 大多数人停在这里，并误以为已经学会 |
| **L2 推导** | 白纸一张，从原始条件推到最终结果，**不看任何材料** | **这才是过关线** |
| **L3 迁移** | 换条件、换结构、加约束仍然能做 | 章末验收 |

**铁律：做完 L2，才能“再看一遍视频”。**

理由：重看视频只会加深 L1。而卡住人的从来是 L1→L2 那一步——“看着答案能懂，合上写不出来”。这一步没有任何捷径，只能闭卷重推。

配套的过关线写法要具体到可判定，例如：

> 给一张没见过的电路图 + 空白纸，15 分钟内从零写出 `A_v`、`R_i`、`R_o`，全程不看书。

“理解了”“掌握了”都不是过关线，“15 分钟内写出来”才是。

## 七、这套东西的三个结构性限制

诚实地说清楚，比吹功能有用：

1. **强依赖题源。** 没有真题/题库，定靶就变成猜，整套流程的收益下降约三分之一。这时的正确动作是去搞题源，而不是让 AI 硬排。
2. **A 型打磨最充分。** 案例是电路课，B/C 型的纪律是从 A 型泛化出来的推论，未经同等强度的实战校准。
3. **不解决动力问题。** 它能保证“每次学习都有产出”，但不能保证你会坐下来。不做基础动作时它会顶回来——顶不顶得住，取决于你有没有把它放进系统提示词。

## 八、版本演进的教训

从 v1 到 v2.0，改的 8 处里有 2 处是硬伤，值得记下来：

- **漏掉了用户最初的核心需求**（“按老师留的练习题讲解并出题”）。教训：需求应该在提示词里有一行对应的硬规则，而不是靠 AI 临场记得。
- **没有“变式题”机制**。这是没有题库时唯一能补题量的手段。教训：**缺口要写进流程，不能指望临场补救。**

其余 6 处（听课指令太窄、缺资料投喂协议、缺节奏控制、诊断覆盖面写错、自相矛盾、漏了答题格式对齐）共性是一样的：**流程里每个“用户会卡住的地方”，都必须有一条对应的规则**。没有规则的地方，AI 就会退化成顺着用户说话。

这不是提示词工程技巧，是流程设计的基本要求。
