# 02 PN结的形成 · 听课示范脚本

> 用途：拿这一课示范"怎么听"这套流程。听完这一课，你以后每节课都照这个模式自己走。
> 集长 46:56 ｜ 实际需要：约 20 分钟听 + 20 分钟动手
> ⚠️ 我给的是**信号词触发**，不是精确时间戳——他讲到什么，你就做什么。合集版本不同，时间点会变。

---

## 第 0 步：开播前，先画好三样东西（2 分钟，最关键）

**这一步是整个流程的要害。** 听课时手一旦开始"找地方写"，注意力就断了。纸先备好，听到什么直接往对应位置填。

在一张 A4 横放，画三个区：

```
┌──────────────────────────────────────────────┐
│ ① 空链（竖着写，留 5 个空）                   │
│                                              │
│   多子浓度差                                  │
│      ↓                                       │
│   ① ________  （一个动词）                    │
│      ↓                                       │
│   ② ________  （一个动词）                    │
│      ↓                                       │
│   ③ ________  （一个名词）                    │
│      ↓                                       │
│   ④ ________  （一个名词）                    │
│      ↓                                       │
│   ⑤ ________  （四个字，讲状态）              │
│                                              │
├───────────────────────┬──────────────────────┤
│ ② 三栏框（画大一点）  │ ③ 卡住区             │
│                       │                      │
│  P 区 │ 窄条 │ N 区   │  ?1 ________         │
│  多子？│      │ 多子？ │  ?2 ________         │
│       │      │        │  ?3 ________         │
│       │ ↑箭头│        │                      │
│       │      │        │  （最多 3 条，超了   │
│  U_D = ____           │   说明这集超纲）     │
└───────────────────────┴──────────────────────┘
```

**为什么要先画**：空链逼你"带着 5 个空去听"，大脑会主动找答案，这是被动看视频和主动听课的分界线。三栏框放在手边，他一画图你就跟着画，不用现找纸。

---

## 第 1 段 · 开场复习（2 倍速，不停不记）

**信号词**：本征半导体、载流子浓度、施主、受主、迁移率、共价键

**手上动作**：无。这段是复习。

**只确认一件事**：P 型多子是空穴，N 型多子是电子。填进三栏框两侧。

**如果这段超过 8 分钟**：直接拖进度条，跳到画面出现"PN 结"三个字。别陪他复习。

---

## 第 2 段 · 扩散与复合（1.25 倍速）

**信号词**：浓度差、扩散、复合、多子向对方运动

**手上动作**：填链的 ① 和 ②——**各写一个动词，不要写句子**。

示范颗粒度：
- ✅ 对：「扩散」「复合」
- ❌ 错：「因为浓度差所以电子从N区跑到P区，然后和空穴复合掉了」

**判定标准**：如果你填的是一个动词，说明你抓到了环节；如果写了一句话，说明你在抄内容，不在建结构。

**这段不暂停**，太简单，暂停是浪费。

---

## 第 3 段 · 全片核心（降到 1 倍速 + 暂停点 1）

**信号词**：留下、不能移动的离子、空间电荷区、耗尽层、内建电场

### 暂停点 1（全片最重要的暂停）

**时机：他一画完那张示意图就暂停。** 不要等讲完，图一出现就停。

**动作（严格按顺序）**：
1. 合上视频，自己画三栏框
2. 窄条里画离子符号：一侧画 `+`，一侧画 `−`
3. 画一条箭头穿过窄条，标 E
4. **画不出来 → 回退 30 秒看他是怎么画的，只看那 30 秒，然后立刻再合上**

**为什么必须自己画**：看懂一张图和画出一张图，是两种不同的记忆。模电后面所有二极管题，你脑子里调用的都是这张图，不是他说的话。

**填链的 ③ 和 ④**：各填一个名词。

**这一段不要快进**。他在讲"离子为什么留下"的那句话，是全片唯一必须听清的一句话——**如果你没听清，就回退听那一句，别整段重听**。

---

## 第 4 段 · 平衡（1.25 倍速 + 暂停点 2）

**信号词**：漂移、动态平衡、扩散电流等于漂移电流、势垒

### 暂停点 2

**时机：他一说"达到平衡"就暂停。**

**动作**：在卡住区写一行你的答案，再播对答案——

> 净电流为零，那两个电流是不是都停了？

**写你的判断，然后对**。这题答错的人极多，答错了不用回看，他接下来会解释。

**填链的 ⑤**：四个字，描述这个状态。

**填 U_D 那一格**：一个 `0.x` 的数字。

---

## 第 5 段 · 正偏与反偏（1.25 倍速 + 暂停点 3）

**信号词**：正向电压、正偏、反向电压、反偏、耗尽层变窄/变宽

### 暂停点 3（这是这一课的体检）

**时机：他讲完正偏、还没开始讲反偏的那一秒。**

**动作**：**先预测，再听。**

在卡住区下面写三行：

```
反偏预测：
耗尽层 → 变宽 / 变窄   （圈一个）
电流   → 变大 / 变小
理由   → ______________________
```

写完再播，立刻对答案。

**这一步是整个流程里最值钱的动作**，因为它能测出你是真通了还是背下了：

| 结果 | 说明 | 下一步 |
|---|---|---|
| 三条都对 | 链是真的通了 | 可以直接进 03 |
| 结论对、理由说不出 | 你记住了正偏的结论，没掌握机制 | 回看第 3 段那张图 |
| 变宽变窄搞反 | 内建电场方向没抓住 | 回到暂停点 1 重画箭头 |

---

## 第 6 段 · 收尾（直接关掉）

**信号词**：势垒电容、扩散电容、定量推导、I = Iₛ(e^(U/U_T) − 1)

**动作：关掉，不用听完。**

理由：这一集结尾必然落到定量公式和结电容上，这两块你现在的考纲用不到（结电容要到第 6 章 f_H 才用，那时会重讲）。**省下的 15 分钟拿去画图和做题。**

---

## 听完后的 10 分钟：交卷格式

不给答案，只给**该写成什么形状**——你照这个形状写，写不出来才算没过。

**① 一句话本质**（一句话，必须含"离子"这个词）
> 耗尽层里之所以有电场，是因为 ______________________。

**② 一张图**（就是暂停点 1 画的那张，检查四项齐不齐）
- [ ] 两侧多子标了
- [ ] 中间离子 `+` `−` 分侧标了
- [ ] 电场箭头有方向
- [ ] U_D 有个数值

**③ 三个回答**
- 0.7 V 是外部加的，还是结自己建立的？
- 反偏时耗尽层变宽还是变窄？
- 温度升高，反向电流变大还是变小？

---

## 卡住了怎么处理

| 卡在哪 | 怎么办 | 能不能跳过 |
|---|---|---|
| 能带图、费米能级 | **完全跳过** | 能，不影响任何一章 |
| 定量公式 | **跳过**，只要定性形状 | 能，第 3 章模型用不到 |
| "为什么少子能过、多子过不去" | 必须搞懂 | **不能跳**，跳了正偏反偏永远是背的 |

**同一处最多回看 30 秒 × 2 次。** 两次还不通 → 标 `?`，往前走，等第 3 章做题时自然会通。

---

## 这一课示范的其实是四件事

1. **听前先画空链** → 带着问题听，不是被动看
2. **图一出现就暂停自己画** → 图是记忆锚点，听懂不算
3. **正偏讲完先预测反偏** → 唯一能测出"真懂还是背结论"的动作
4. **信号词决定倍速和跳过** → 46 分钟压到 20 分钟，靠的是判断力不是勤奋

**这四条以后每节课都照用。** 换成第 4 章、第 8 章，变的只是链的内容和暂停的位置，这四个动作不变。
