# 考点映射表 · 知识 → 卷面

> 用途：每学一课，就在这张表上登记"这些结论到底考在哪"。
> 原则：**没有去处的知识点，只记结论；有去处的，必须练到能做对题。**
> 依据：题库 65 题（详见[`exam-blueprint.md`](exam-blueprint.md)）

---

## 第 3 章 二极管 · 前半（02–05 课）

| 学到的结论 | 卷子上会怎么问 | 对应题库 | 要求 |
|---|---|---|---|
| **正偏导通 / 反偏截止** | 给一串小图，判二极管通不通、求输出电压 | 3章 题5、题6（共 7 图） | ★必考。断开法，2 分钟/题 |
| **U_D ≈ 0.7 V 是内建势垒** | 所有恒压降模型计算的起点 | 3章 题3、4、7 | ★必考。要能说出"这 0.7V 不是外加的" |
| **反偏 ≈ 断开** | 判通断时的默认假设；稳压管未击穿时按断开处理 | 3章 题5、6、9 | ★必考 |
| **I_S 随温度升高翻倍** | 温度对 Q 点的影响；稳压管温度系数 | 5章 题1、3；3章 题9 | 考。只需知道方向 + 量级（10℃ 翻倍） |
| **耗尽层宽度随反偏电压变化** | 结电容 → f_H、密勒效应 | 6章 题1、2 | 考，但在第 6 章才用。本课只留"会变"这个结论 |
| **扩散 / 复合机制** | **不直接考** | — | 只记结论，不深究。这就是为什么可以快进 |

**这一课的性质：支撑课，不是考点课。**
PN 结形成本身不会单独出题（题库第 3 章 10 题里没有一道问它）。它的作用是给后面四件事提供解释：**为什么能等效成 0.7V 电池、为什么反偏能当断开、为什么判通断要看偏置、为什么温度会坏事。**

所以这一课的正确投入量是：**够用来支撑那四件事，不多学一步。**

## 第 3 章 二极管 · 后半（03–05 课）

| 学到的结论 | 卷子上会怎么问 | 对应题库 | 要求 |
|---|---|---|---|
| **三种模型**（理想／恒压降／折线） | 判通断、算输出、选模型 | 3-5、3-6 | ★必考，全章地基 |
| **理想 vs 恒压降差 1.4 V** | 桥式整流波形要削掉 1.4 V | 3-1、3-3 | ★必考 |
| **恒压降模型（0.7 V）** | 限幅、钳位、稳压计算 | 3-3、3-4、3-7 | ★必考 |
| **折线模型的斜率 = r_d** | 直接接上 05 集的小信号 | 3-7 | 必考，是 r_d 的来源 |
| **图解法／负载线** | 第 4、5 章放大电路定 Q 点 | 4章 题1、题3 | 跨章必用，本章先埋伏 |
| **小信号 r_d = V_T/I_D** | 同一题先算直流，再用 r_d 求变化量 | 3-7 | ★★本章最值，全书方法论缩影 |
| **稳压管反向击穿稳压** | 画限幅波形（单管／双管反串） | 3-9 | ★必考 |
| **限流电阻 R 的取值范围** | 求 R、R_L 范围（最坏情况） | 3-8 | ★必考 |
| **稳压管功率 P_Z** | 写功率表达式 + 最大最小条件 | 3-10 | ★必考 |

**这三集的性质判断（决定精力分配）：**

| 集 | 性质 | 理由 |
|---|---|---|
| 03 特性 | 基础课 | 只为判通断提供阈值和曲线形状，本身不单独出大题 |
| 04 直流等效 | **核心考点课** | 三种模型是全章第一步，每道题都要先"把二极管换成什么" |
| 05 微变+稳压 | **★★主得分区** | 题 7、8、9、10 **共 4 题全落在这集**，占本章 40% |

→ **结论：04 和 05 花大头，03 够用即止。**

## 用法说明

1. **每学一课，先看这张表有没有这一课。** 有 → 按"要求"栏的强度学；没有 → 说明这课是支撑课，学到能解释考点为止。
2. **表里写"不直接考"的，就是你敢快进的地方。** 这就是倍速和跳过的依据，不是凭感觉。
3. 学到新章节时往表里加行。**这张表越长，你越知道自己该在哪停手。**
4. 如果某个考点在表里找不到对应题库题 → 说明题库没覆盖，要额外从课本课后题补。
