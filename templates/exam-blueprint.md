# 题型分布表（Exam Blueprint）

> **作用**：这是整套流程唯一的依据。没有这张表就开始学，是这类学习失败的第一原因。
> **产出时机**：拿到真题/题库之后，排路线之前。

---

## 表结构

| 章节 | 题号 | 分值 | 问法（原题怎么问的） | 频次（几套卷里出现几次） |
|---|---|---|---|---|
| | | | | |
| | | | | |

**四列必须都有**。“问法”一栏不要写知识点，写**原题的动词**——是“求”、是“判断”、还是“画出波形”，这三种的练法完全不同。

---

## 填完之后必须做的三件事

### ① 砍内容

按分值密度排序，不考的划掉。**不要因为“重要”而保留。**

判断标准只有一条：这张表里有没有去处。没有去处的，只记一句结论。

### ② 单独列出「必须会但不考的工具」

这类东西不出题，但藏在每道大题的**第二步**。它们不能删，只能压缩成结论。

例：判三极管工作区、虚短虚断、单位换算、判二极管通断。

### ③ 给一句战略判断

例如：

> 这张卷子 60% 的分集中在三个模块（单管放大、反馈、功放），其余四章只需认得出、能答结论。

这句话决定后面所有时间怎么分。

---

## 没有题源时怎么办

1. 按该学科通用高频权重排一份，**必须明确告知误差范围**（“这是通用版，会浪费约三分之一时间”）。
2. 资料到位后**立刻重排**，不许沿用通用版。
3. 用**变式训练**补题量：每道真题拆 4 个变式（换对象 / 换条件 / 加约束 / 加干扰）。

---

## 反推技巧：从“缺什么”判断“不考什么”

题库/课件如果按章节分文件，**缺的那几章大概率不考**。这比问老师可靠，也比课件目录可靠。

但要看反例：某些章的思想可能被塞进别的章里考（比如“有源负载”属第 7 章，却出现在第 4 章的 MOS 题里）。**查反例的方法是搜关键词，不是看目录。**
