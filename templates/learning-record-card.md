# 学习档案卡（Learning Record Card）

> **作用**：任何 AI 都没有跨会话记忆。这张卡把“你学到哪、欠了什么、下一步干什么”外置成一个文件。
> 换 AI 时粘这张卡，10 秒接上，不用重讲历史。
>
> **更新时机**：每完成一个阶段 / 每次换平台前。

---

## 空白模板

```text
【学习档案卡】v__  更新日期：____
学科：              类型：A计算/B记忆/C技能/D综合
考核日：            每日投入：__ h
教材/骨架：          符号或术语体系：______

依赖链：__ → __ → __ → __ → __
判断类技能（不许欠账）：______
该学科的"两条线"：______ / ______
三张核心对照表：①______ ②______ ③______

必须会但不考的工具：______
已完成阶段：__ / 当前阶段：__
欠账清单：①______ ②______
错题数：__   最近周测：__/10

下一步第一件事：______
```

---

## 每一格填什么（以及为什么必须填）

| 格子 | 填什么 | 不填的后果 |
|---|---|---|
| **类型** | A/B/C/D | 走错分支。记忆型学科用计算型纪律＝白费时间 |
| **符号/术语体系** | 下标、符号写法、单位、有效数字精度 | 学一套、写一套，按阅卷标准白扣分 |
| **依赖链** | 每层是下层的**工具**，不是并列知识点 | 路线退化成“按教材章节顺序” |
| **判断类技能** | 判类型 / 判状态 / 判方向 / 判结构 | 这类技能一欠账就滚雪球，必须写出来钉死 |
| **两条线** | 该学科最容易混淆的两条计算/推理路径 | 混在一起算，必错（如“直流求 Q / 交流求增益”） |
| **三张表** | 必须手画、考前直接背的对照表 | 临考才发现要背的东西散落在各章 |
| **必须会但不考** | 藏在每道大题第二步的工具 | 因为“不考”被误删，后面每道题都卡第一步 |
| **欠账清单** | 标记“先往前走、回头再还”的点 | 忘了还，考前全虚 |
| **下一步第一件事** | 一个具体动作，不是“学第 3 章” | 打开电脑不知道干什么 |

---

## 换 AI 时的标准三步

```text
1. 在旧 AI 里说：“输出当前学习档案卡”
2. 到新 AI 里：粘提示词 / 技能 → 粘这张卡
3. 说一句：“按这个档案继续，先复述我的起点和下一步”
```

第 3 步是质检：**如果它复述不对，说明卡填得有歧义，改卡**，别急着往下走。
